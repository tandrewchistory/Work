How to Play

  1. Split the class into 2–6 teams and give each one a name.
  2. A team picks a category and dollar value from the board.
  3. Read the clue aloud. Teams race to answer.
  4. Click “Reveal Response” to check the answer (and its explainer, if you wrote one), then award points to whichever team got it (or dock points for a wrong guess).
  5. Opened the wrong tile by mistake? Click “Return to Board” (or just click outside the card, or press Escape) to back out — the tile stays unplayed. “Close (No Award)” is different: it marks the clue as done with no points awarded.
  6. Watch for the hidden Daily Double — same rules, but only one team gets to answer.
  7. When every tile is gone, the highest score wins — or click “End Game” any time to finish early and see the winner.
  8. Teaching a different topic? Click “Edit Board” to rewrite the title, categories, and every clue — add or remove categories and rows to fit your subject, no code required.
  9. Want students to buzz in from their own devices? Click “Buzzer” to connect a free Firebase project — it’s entirely optional, and the board works exactly the same without it.

First-time setup instructions
  1. Go to the Firebase console, sign in with Google, and create a free project.
  2. In the project, open Build → Realtime Database, click Create Database, and start in locked mode.
  3. Open the Realtime Database’s Rules tab, replace the contents with the JSON below, and publish:
{
  "rules": {
    "rooms": {
      "$room": {
        ".read": true,
        "round": { ".write": "auth != null" },
        "lock": { ".write": "auth != null && (newData.val() == null || !data.exists())" }
      }
    }
  }
}
  1. Open Build → Authentication → Sign-in method and enable both the Google and Anonymous providers.
  2. Open Project settings (gear icon) → scroll to “Your apps” → add a Web app → copy the firebaseConfig object it shows you into the field above.
  3. Host the separate classroom-showdown-buzzer.html file somewhere public (e.g. GitHub Pages) and set its URL above — that’s the page students open to buzz in.
  4. Pick a room code, click Save & Connect, then Copy Student Link and share it with your class.
